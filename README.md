A 2D desktop game built in **C++** demonstrating fundamental game architecture, custom game loops, and physics collision detection.

* **Physics & Collision Handling:** Collision detection for entity interaction.
* **Player Controls & Movement:** Keyboard-driven input handling.

* **Build Tools:** Visual Studio / VS Code
* **Asset Creation:** Custom 2D Graphic Layouts
